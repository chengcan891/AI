# 排版与尺寸规则

## 字段排版

先看字段内部，再看字段之间的分列。长名称、SN、译文、单位和缺省值按实际列宽检查。

| 排版 | 检查要点 | 参照 |
|---|---|---|
| 上标签、下值 | `text_3` 标签配 `text_1_content` 普通值，同侧对齐，组内间距小于组间间距 | `fragment_field_summary.xml` |
| 左标签、右值或控件 | 主要标签用 `text_2`，普通值用 `text_1_content`。检查两侧对齐与长值空间 | `fragment_home_user_device.xml`、`fragment_harrow_field_planning.xml` |
| 成组数据 | 每个值与自己的标签同侧对齐，同组核对精度和单位 | `fragment_field_summary.xml` 的 LON／LAT |

- 「上标签、下值」含下拉字段。对照同用途页面，同时查看标签、收起态当前值和展开选项的实际字号、颜色与字重。普通值与选项核对是否沿用 `text_1_content`，并检查 XML 或运行时是否覆盖。

## 操作区

先分辨右下固定宽、整行等分、随内容测量。比较同用途页面的字面 `dp`、`@dimen`、权重、最小宽和图标。

- 作业编辑页右下固定按钮：取消 102dp，带勾确定 112dp，高度 `button_size_normal`，间距 `page_padding_default`。参照普通导航线、耙地线、标记物编辑页。遇到 128dp，指出多出的 16dp，并核对译文和图标是否需要这段空间。
- 整行等分：任务编辑弹窗、用户资料页使用 `0dp` 加等权重，沿用各自高度与间距。

## 外边缘与状态

- 循环线和耙地线编辑页的地图、参数卡片与顶部页签共用 `page_padding_large` 外边距，右侧卡片与确定按钮外边缘对齐。嵌套 Fragment 要合计父容器 margin 和子布局 padding。
- 弹窗和侧面板从标题文字的下缘核对到首个可见字段的上缘。合计标题组件内部余量、面板或内容区 padding、父子布局 margin 以及占位，避免只看首项的单个 margin。对照同用途面板与后续分组间距，记录各段来源和实际偏差。截图可用于定位，尺寸或显示状态需设备确认时标记待实机核对。
- 顶部导航和表单内选项分别比较同类控件。保留选中、禁用、错误、红绿状态及地图着色。普通前景和背景检查浅深主题、选择器及运行时覆盖。
- 替换输入样式前核对输入类型、长度、单行和 IME 动作；替换布局属性前核对实际测量、滚动和长内容。

## 资源索引

`scripts/index_ui.py` 可搜索布局、样式、主题、颜色、尺寸与 XML 图形。维护覆盖记录时可用 `--output <临时文件>.jsonl`，仅回传计数和相关片段。索引不解析运行时代码和设备渲染。
