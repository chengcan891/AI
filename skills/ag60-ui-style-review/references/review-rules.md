# 排版与尺寸规则

## 生效样式核对

- **背景与卡片**：沿宿主、根布局和 include 找到可见背景，查看 drawable、tint 和主题如何解析。宿主提供页面底色且内容已分成独立卡片时，对照同类页检查子页根容器是否额外铺了一层卡片背景；分别观察卡片之间和内容下方的留白。对可选中的卡片同时追到 selector 与选中状态的设置处，分别对照默认、选中和禁用态。背景在运行时着色或叠加时，核对文字与实际合成背景的对比度，覆盖浅深主题和容易读不清的状态。嵌入式地图沿用公共卡片圆角，并用实机确认实际地图画面及四角裁剪。先对照地图选点页的普通 FrameLayout，它在代码中启用轮廓裁剪。XML 的 clipToOutline 从 API 31 起受支持；只改布局时可沿用项目已有的 CardView，由控件启用相同的裁剪机制。
- **文字与输入**：分别定位标签、值和展开项的实际视图，包括公共控件内部和 adapter 行布局。核对字号、字重、颜色的来源和覆盖。输入控件同时核对实际的提示色、错误态及输入属性。
- **操作区**：先判定固定宽、等分或随内容测量。核对父容器约束、控件尺寸、图标、主次配色及运行时显隐、禁用状态，再按下方操作区规则对照。

## 字段排版

先看字段内部，再看字段之间的分列。长名称、SN、译文、单位和缺省值按实际列宽检查。

| 排版 | 检查要点 | 参照 |
|---|---|---|
| 上标签、下值 | `text_3` 标签配 `text_1_content` 普通值，同侧对齐，组内间距小于组间间距 | `fragment_field_summary.xml` |
| 左标签、右值或控件 | 主要标签用 `text_2`，普通值用 `text_1_content`。检查两侧对齐与长值空间 | `fragment_home_user_device.xml`、`fragment_harrow_field_planning.xml` |
| 成组数据 | 每个值与自己的标签同侧对齐，同组核对精度和单位 | `fragment_field_summary.xml` 的 LON／LAT |

- 「上标签、下值」含下拉字段。对照同用途页面，同时查看标签、收起态当前值和展开选项的实际字号、颜色与字重。普通值与选项核对是否沿用 `text_1_content`，并检查 XML 或运行时是否覆盖。

## 操作区

先分辨右下固定宽、整行等分、随内容测量。比较同用途页面的字面 `dp`、`@dimen`、权重、最小宽和图标。

- 作业编辑页右下固定按钮：取消 102dp，带勾确定 112dp，高度 `button_size_normal`，按钮间距见[外边缘与状态](#外边缘与状态)。参照普通导航线、耙地线、标记物编辑页。遇到 128dp，指出多出的 16dp，并核对译文和图标是否需要这段空间。
- 整行等分：任务编辑弹窗、用户资料页使用 `0dp` 加等权重，沿用各自高度与间距。

## 外边缘与状态

[当前改动页面的审查依据](review-coverage.md#当前改动页面的审查依据)列出源码参照、原有用法和实机待核项。

| 核对位置 | 净距 | 适用范围和参照 |
|---|---|---|
| 页面左右边缘 → 主内容外缘 | 各 18dp（`page_padding_horizontal`） | 普通页面的页签、主体卡片和固定底栏对齐。田块页的 10dp 父内边距加 8dp 子外边距同样符合。 |
| 标题栏底边 → 页签上缘 | 10dp（`page_padding_default`） | 有顶部页签的导航线编辑页，参照 AB 线、耙地线和循环线。 |
| 页签底边 → 首张卡片或地图 | 10dp（`page_padding_default`） | 导航线编辑的基本信息、分组线和田块规划。 |
| 同一内容区上下相邻卡片 | 8dp（`view_margin_default`） | 参照耙地线「田块规划」，检查卡片边缘到边缘的距离。 |
| 同一卡片内上下连续的同高输入框 | 8dp（`view_margin_default`） | 普通表单同一卡片内连续同高输入行的默认标准，参照 AB 线经纬度和分组线参数。测量上一输入框下缘到下一输入框上缘，合计行内留白、行间距和最小行高余量。有专用规范的控件按其规范核对。 |
| 地图或示意图区 → 右侧参数栏 | 8dp（`view_margin_default`） | 导航线编辑的左右分栏，参照耙地线和循环线「田块规划」，合计两栏的相邻边距。 |
| 固定「取消／确定」按钮下缘 → 页面底边 | 10dp（`page_padding_default`） | 导航线编辑的各页签，切换时核对按钮下缘齐平。 |
| 固定「取消」按钮 → 「确定」按钮 | 10dp（`page_padding_default`） | 作业编辑页右下固定操作区，参照导航线和标记物编辑页。 |

- 所有净距均按实际可见边缘核对。累计宿主与子布局的 margin、padding、列表项间距以及固定高度容器内部的对齐余量，报告每一段来源。页面可切换为全屏时，分别计算侧栏显示与隐藏时的净距。隐藏后应随之消失的分栏间距设在可隐藏的侧栏上，对照边界工具全屏地图的左右边距。
- 同一行并排字段卡片、卡片内部的内边距、滚动内容到固定底栏的间距，按同用途参照核对。发现项目里的现有用法不一致时，记录差异并说明适用场景。有专用规范的弹窗、侧栏或全屏地图按相应规范检查。
- 弹窗和侧面板从标题文字的下缘核对到首个可见字段的上缘。合计标题组件内部余量、面板或内容区 padding、父子布局 margin 以及占位，避免只看首项的单个 margin。对照同用途面板与后续分组间距，记录各段来源和实际偏差。截图可用于定位，尺寸或显示状态需设备确认时标记待实机核对。
- 顶部导航和表单内选项分别比较同类控件。保留选中、禁用、错误、红绿状态及地图着色。普通前景和背景检查浅深主题、选择器及运行时覆盖。
- 替换输入样式前核对输入类型、长度、单行和 IME 动作；替换布局属性前核对实际测量、滚动和长内容。可缩放的容器要核算固定子控件的最小占用，窄屏布局要能容纳完整的触控区。

## 资源索引

`scripts/index_ui.py` 可搜索布局、样式、主题、颜色、尺寸与 XML 图形。维护覆盖记录时可用 `--output <临时文件>.jsonl`，仅回传计数和相关片段。索引不解析运行时代码和设备渲染。
