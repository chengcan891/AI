# 布局试查记录

2026-11-13 对仓库中 `rg --files` 枚举到的 351 个 Android 布局 XML 做了只读结构扫描，全部可解析。按文件名统计包括 178 个 `fragment_*`、8 个 `activity_*`、49 个 `dialog_*`，其余 116 个为列表项、公共控件等其他布局。文件数按资源文件计算，页面可能复用多个布局。扫描范围是 XML，运行时界面仍需按需追踪代码。

| 模块 | 扫描布局数 | 代表性规则复核 |
|---|---:|---|
| `component-home` | 73 | 服务状态色和徽标、用户与设备的卡片标题、帮助入口和协议正文各有用途 |
| `component-work` | 71 | 任务列表项保留选中背景，编辑弹窗用公共容器和主次按钮，测线页保留分段页签 |
| `component-device` | 53 | 车辆传感器下拉框的外层与内层分开核对，RTK 模式切换保留单选态 |
| `component-setting` | 48 | 关于页按需保留行分隔，手柄页复用开关和列表样式，系统参数沿 `include` 追到实际行布局 |
| `component-common` | 21 | 文件导入页的操作按钮和提示颜色分别按用途检查 |
| `component-isobus` | 13 | 功能卡片使用紧凑、单行的专用文字样式 |
| `app` | 29 | 旧数据迁移的弹窗容器、主次按钮、进度条与辅助文字分开判断 |
| `common-view` | 29 | 公共角度输入的度数与度分秒样式按控件配置核对 |
| 其他模块 | 14 | 纳入布局结构扫描 |

批量扫描记录了各布局的样式、文字覆盖、状态背景、控件和引用。代表性复核用于判断样式的使用时机，计数只反映使用范围。例如 119 个布局使用 `drawable_card_1_with_border`，24 个使用 `drawable_bg_active_with_border`，29 个使用 `divide_line`，117 个对 `text_*` 样式覆盖了文字颜色。判断替换前仍需确认覆盖属性的业务用途。

第二轮按规则模拟筛查了同一批布局。16 个布局含有使用 `text_2` 并覆盖为主文字色的 TextView，需要按文字角色判断是否适合 `text_1_content`。另有 25 个布局直接引用错误或正常状态色，28 个使用其他按钮配色，32 个给公共输入样式额外指定输入类型、长度或键盘动作，7 个含 `include`。这些命中用于安排复核。
