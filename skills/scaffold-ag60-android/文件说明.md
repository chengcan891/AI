# 文件说明（前缀 ↔ 扩展名）

本技能包内的**源码/资源/清单类文件**不以真实扩展名存放。  
存储格式：`{前缀}__{文件主名}`（无扩展名；亦兼容 `{前缀}_{文件主名}`）。技能包内文件**保持**此前缀形态，不要在技能包内改名。

## 前缀表

| 前缀 | 真实扩展名 | 示例（技能内 → 生成后） |
|------|------------|-------------------------|
| `kt__` / `kt_` | `.kt` | `kt__CommonDeviceService` → `CommonDeviceService.kt` |
| `kts__` | `.kts` | `kts__libs` → `libs.kts` |
| `gradlekts__` | `.gradle.kts` | `gradlekts__build` → `build.gradle.kts` |
| `xml__` | `.xml` | `xml__styles` → `styles.xml` |
| `pro__` | `.pro` | `pro__consumer-rules` → `consumer-rules.pro` |
| `properties__` | `.properties` | `properties__gradle` → `gradle.properties` |
| `txt__` | `.txt` | `txt__common-view-classes` → `common-view-classes.txt` |
| `md__` | `.md` | `md__conventions` → `conventions.md` |
| `java__` | `.java` | `java__Foo` → `Foo.java` |
| `gradle__` | `.gradle` | `gradle__build` → `build.gradle` |
| `gitignore__` | `.gitignore` | `gitignore__ROOT` → `.gitignore` |

机器可读映射：`map__prefixes`（TAB 分隔）。

## 不转换（保持真实扩展名）

| 路径 | 原因 |
|------|------|
| `SKILL.md` / 根 `README.md` | Cursor/技能加载需要 |
| `scripts/scaffold.ps1` `scripts/scaffold.sh` | 可执行脚本 |
| 本 `文件说明.md` | 清单自身 |

## 物化算法（脚手架）— 禁止就地重命名

加密或路径绑定文件在 **Rename-Item / Move-Item / mv** 后会失效。因此脚手架必须：

1. 复制 `templates/skeleton` 到目标工程（技能包原文件不动）。
2. 展开 `__PKG_PATH__`：对目录内每个**文件** `ReadAllBytes` → 写入包路径下同名相对路径 → 再删除旧 `__PKG_PATH__` 树（**不要**对内容文件做 Move-Item）。
3. 对匹配 `{前缀}__{主名}`（或已知前缀的 `{前缀}_{主名}`）且无扩展名的文件：
   - `bytes = ReadAllBytes(源)`
   - `WriteAllBytes(目录/{主名}{扩展名}, bytes)`（`gitignore__*` → `.gitignore`）
   - `Remove-Item` 目标里的无扩展名副本（删除，不是重命名）
4. 再做 `__APP_NAME__` / `__PKG_ROOT__` 等占位符替换。
5. 合并 `assets/res-values` 时同样走读出/写出物化。

## Encryption policy (hard rules)

- Skill pack MUST be plaintext: templates/ assets/ seed-plain/ reference/ must NOT contain E-SafeNet LOCK ciphertext shells. Templates must be ContentIO-readable plaintext; if no seed match, plaintext SCAFFOLD_STUB is OK.
- Generated projects MAY be encrypted: writing to paths like D:\WorkSpace\git\... may re-encrypt files by local policy. That is expected. Do NOT decrypt or clear locks on generated projects. Cursor / Android Studio / cmd type can still read plaintext.
- Maintain skill pack by ContentIO read-then-write from ag6.0 or seed-plain into the skill directory. Never Copy/Rename LOCK shells into the skill pack.
- CN: skill pack plaintext only; generated project may encrypt; do not decrypt generated project.
